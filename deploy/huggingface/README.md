# ShopAssist

An AI customer-support agent for an online store. It tracks orders, checks return eligibility, creates returns and replacements, cancels orders and hands over to humans, using tools on a live order database. Its answers are grounded in real public help-center pages, and every reply comes with a trace of what the agent did.

**Unofficial portfolio demo, not affiliated with Amazon.** Store policies come from Amazon.in's public help pages, which this Space fetches while building. Customers and orders are synthetic.

Design notes, evaluation results and source code are in the project repository.
